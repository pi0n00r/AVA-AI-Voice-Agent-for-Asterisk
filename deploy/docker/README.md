# Ava Docker package

This self-contained package brings up Ava's WebUI, voice engine, and local
speech stack from published images. Operators configure `.env`; versioned YAML
and PBX defaults are generated by the package and then maintained through the
WebUI. You do not need a source checkout.

## Install

Requirements: Linux, Docker Engine with the Compose plugin and IPv6 enabled,
`openssl`, Python 3, `curl`, and `unzip`.

```bash
cp .env.example .env
./install.sh starter
```

Open `http://HOST:3003`. Sign in as `admin` using the one-time password stored
locally in `config/.first-run-password`, then change it immediately.

The starter profile includes a sandbox Asterisk server. Register a SIP client
with the username and password in `.env`, then call extension `700`.

For an existing Asterisk or FreePBX server, set its ARI host and credentials in
`.env`, then run:

```bash
./install.sh external-pbx
```

The external PBX must route calls into `Stasis(asterisk-ai-voice-agent)`.
Ava owns AudioSocket creation after the channel enters Stasis; do not add a
second `AudioSocket()` application to the dialplan.

## Operations

```bash
docker compose ps
docker compose logs --tail=100
docker compose pull
docker compose up -d
```

`SOURCE.txt` identifies the exact maintained-fork source. Verify every packaged
file before installation with:

```bash
sha256sum --check PACKAGE-MANIFEST.sha256
```

Persistent data lives in named Docker volumes and the package's `config/`,
`models/`, `data/`, `logs/`, and `asterisk_media/` directories. The installer
does not replace an existing `.env` or `config/ai-agent.yaml`.

The WebUI container mounts the Docker socket so its service controls work. That
grants host-level Docker authority; expose the WebUI only through a trusted LAN,
VPN, or authenticated reverse proxy.
